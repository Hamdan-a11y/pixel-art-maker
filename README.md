# Pixel Art Maker

A browser-based pixel art drawing application built with vanilla HTML, CSS, and JavaScript using the HTML5 Canvas API.

## Features

- Draw with customizable preset color palette or custom hex color picker
- Tools: Pen, Eraser, and Flood Fill (Paint Bucket)
- Grid sizes: 16x16, 32x32, and 64x64
- Translucent cursor hover preview
- Export artwork directly to downloadable PNG without grid lines

## Tech Stack

- HTML5 Canvas
- Vanilla CSS3
- Vanilla JavaScript
